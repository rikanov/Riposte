### 📱 Android

Download the **.apk** file directly to your device. 

1. Open a file manager and tap on the downloaded `app-release.apk` file.

2. Your device may ask for permission to "Install unknown apps" from your browser or file manager. Go to Settings, enable the permission, and go back to complete the installation.

3. Once installed, launch **Riposte** from your app drawer!

### 🪟 Windows

You can choose between the standalone executable or the traditional installer.

* **.exe (Recommended):** Simply download the `Riposte-1.0.1.exe` file and double-click to run the game immediately. No installation required!

* **.msi:** Download the `Riposte-1.0.1.msi` file and double-click to launch the Windows Setup wizard. It will install the game to your system and create a Start Menu shortcut.

*Note: Since this is an indie game, Windows SmartScreen might show a "Windows protected your PC" warning. Click **"More info"** and then **"Run anyway"**.*

### 🐧 Linux

Native KMP builds are provided for both Debian and RedHat-based distributions. The game installs cleanly to the `/opt/Riposte` directory and will automatically add a shortcut to your desktop environment's application launcher.

**Ubuntu / Debian / Mint (.deb)**

Open your terminal in the download folder and run:

`sudo apt install ./riposte_1.0.1_amd64.deb`

*(Alternatively, you can double-click the file to install it via your graphical software center like GDebi or Discover).*

**Fedora / openSUSE (.rpm)**

Open your terminal in the download folder and run:

`sudo zypper install ./riposte-1.0.1-1.x86_64.rpm` (for openSUSE)

`sudo dnf install ./riposte-1.0.1-1.x86_64.rpm` (for Fedora)
